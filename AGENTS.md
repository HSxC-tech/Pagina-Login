# AGENTS.md - Pagina-Login

## Regras de execução

1. **Executar somente o que foi pedido:** Não adicionar melhorias, refatorações, arquivos ou comportamentos extras além do solicitado.
2. **Confirmar entendimento antes de agir:** Sempre que o usuário enviar um prompt neste projeto, a IA deve:
   - Dizer o que entendeu do pedido;
   - Dizer o que vai fazer;
   - Só depois executar.
3. **Respostas curtas para perguntas fechadas:** Se o usuário fizer uma pergunta que pode ser respondida com "Sim" ou "Não", responder **somente** "Sim" ou "Não", sem explicar antes que ele peça.
